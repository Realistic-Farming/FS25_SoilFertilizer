## Near-term (2026-08-05 wave)
- [x] Dry products are haulable (SF #773, Arissani ruled PARITY 2026-08-05): our twelve dry products join `BULK` and `AUGERWAGON`, the two transport categories vanilla FERTILIZER is already in. The gap was never the products: each already declares `isBulkType="true"`, which per `FillTypeDesc.lua:287` only governs being SOLD as bulk. We had extended the APPLICATION categories (FERTILIZER, LIQUIDFERTILIZER) and never a TRANSPORT one, so a player could spread urea and could not tip it. Category extension confirmed additive at source (`FillTypeManager.lua:145` reuses an existing index when `isBaseType` is false, and mods load with false at `:85`), so nothing is displaced from BULK. The liquid half of the parity needs no change: vanilla LIQUIDFERTILIZER is in SPRAYER only and never in LIQUID, so a liquid rides the machine that applies it, which our LIQUIDFERTILIZER line already covers. Built on development, PR open.
- [x] Organic market premium provenance (OM-213, SF half): `OrganicCertification.organicFraction[farmId][fillTypeIndex]` accumulates the farm-level organic share of each harvested fill type with the D1 blend, folded per harvest pass from the combine's own `farmId`/`outputFillType` (dedi-safe, never the local-player read). Publishes `getFarmOrganicFraction(farmId, fillTypeIndex)` for MarketDynamics' OrganicPremium modifier. Persists via soilData.xml (safety copy) and the StateLedger block. Ships LOCKED with the premium; unlock gated on the FarmTablet market-report line (Wizard lane). Built on development, PR open.
- [x] Spray-paint streak re-fix (RSF-762, fast track): `SoilValueMaps:addPaintStrip` is a new additive parallelogram painter; `paintBoomStrip` is reimplemented as a swept quad (previous painted boom line to current line) that never overlaps, self-heals a failed tick by spanning the gap, and conserves the tick's nutrient mass with the strip's own area as denominator. `markBoomCells` is now coverage-only. 34 assertions across the rewritten #735 test and the new RSF-762 bar. Built on development, PR open.
